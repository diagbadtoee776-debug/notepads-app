# DevVault - PRD (Product Requirements Document)

Project Name: DevVault (formerly Notepads)
Tagline: The Offline-First Knowledge Hub for Computer Science Students.

## 1. The Problem
University students struggle with fragmented study materials. Notes are
scattered across notebooks, WhatsApp messages, and random folders. Sharing
code on messaging apps breaks the formatting. Students in areas with poor
internet connectivity cannot access cloud tools like Notion or Google Docs.
When seniors graduate, their valuable notes and past questions are lost forever.

## 2. The Solution
DevVault is a cross-platform application (Phone, PC, Web) that serves as a
personal brain-backup and a departmental knowledge base. It captures text,
code, photos, voice, music and video. It works entirely offline and syncs
to the cloud automatically when internet is available.

## 3. Core Features (Original + Upgraded)
- Notes: formatted text, code blocks, checklists
- Media: attach photos, record voice, speech-to-text, play music & video inside notes
- Organization: folders, pin, trash + restore, instant search
- Offline-first: works with zero internet, auto-sync when online
- TV Cast: present notes on smart TVs / projectors
- Themes: light/dark/system + accent colors
- Backup & restore
- Share Link: secret read-only link for any note
- Shared Folders: collaborate with friends via username / QR invite
- Department Hall: public board per department (announcements, past questions)
- AI Study Buddy: explain, quiz, summarize, code help (online bonus)
- Profile: username, department, avatar, app lock

## 4. Core Value Proposition (The 3 Rooms)
- Private Room: personal offline-first diary.
- Friends Room: secure sharing & study groups.
- Department Hall: department-wide knowledge board.

## 5. Target Audience
Primary: Computer Science students and faculty.
Secondary: any university department (Medicine, Law, Engineering).

## 6. Success Metrics
- Create a note in 2 taps.
- 100% offline core functionality.
- Search under 1 second.
- Zero loss of notes on crash.
